# Rumi face vocabulary

Every glyph is drawn in the logo's language: white, thin (~2.5% of patch width), glowing pale-blue
`#A8C7FF`, on navy `#001F3F`. "Ref" = the approved reference render in `faces/` it was learned from.

## Eyes

| Glyph | Looks like | Means | Ref |
|---|---|---|---|
| `dot` | ● | neutral / attentive - the logo dot | ref-neutral, ref-angry |
| `dot:s` / `dot:l` | small ● / big ● | asymmetry = curious, confused, nervous | ref-curious, ref-confused, ref-nervous |
| `arch` | ^ | happy-closed, laughing softly | ref-clap |
| `squint` | > < | laughing hard, energized, celebrating | ref-celebrate, ref-energized |
| `closed` | ︶ | asleep, blissful | ref-sleeping |
| `wink` | ‿ (one eye) | wink, salute | ref-salute |
| `lidded` | ◒ (top cut) | proud, smug, tired, loading | ref-proud, ref-shy |
| `lid:sad` / `lid:angry` | slanted lid | sad droop (outer up) / angry (inner down) | - |
| `dome` | ⌓ + brow ⌒ | worried, pleading, crying | ref-worried |
| `x` | ✕ | error, knocked out | ref-error |
| `spiral` | 🌀 | dizzy, mind-blown | ref-mind-blown |
| `heart` | ♥ | love, adoration | ref-heart-eyes |
| `star` | ★ | starstruck, 100 | ref-starstruck |
| `look:up/down/side` | ◉ ring + pupil | thinking, reading, shy glance, eye-roll | - |

## Mouths

| Glyph | Looks like | Means | Ref |
|---|---|---|---|
| `smile:s/m/l` | ⌣ | content → happy → delighted | ref-neutral, ref-sleeping |
| `open:s/l` | filled D | talking / laughing out loud | ref-clap, ref-starstruck, ref-proud |
| `frown` | ⌢ | sad, angry (with body cue), low battery | ref-angry |

| `o` | • | surprised, dizzy | ref-mind-blown |
| `openfrown` | filled ∩ small | worried, pleading | ref-worried |
| `smirk` | ⌣ tilted | smug, thinking, cool | - |

## Link

`link=True` replaces the mouth with the logo's exact connecting curve (dots → curve → dots). The
resting face `happy` is always linked - it IS the logo. `heart-eyes` and `shy` are linked because the
references show it. Anything else: disconnect if it reads better.

## Body cues that pair with faces (these live OUTSIDE the patch)

💢 anger mark · sweat drops + shake lines · sparks / lightning · floating hearts · bubbles / confetti ·
dizzy ring · glitch pixels · zZz · ? / ! · sparkles · blush glow on the body beside the patch · squash
(laugh, sad slump) and stretch (surprised, idea) of the whole body · pseudopod gestures and gel props.
